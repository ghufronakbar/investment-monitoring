# 2.1 Sistem Informasi Monitoring Proyek

Sistem informasi monitoring proyek adalah sistem yang digunakan untuk mengumpulkan, mengelola, dan menyajikan informasi terkait kondisi proyek secara terstruktur. Pada proyek infrastruktur, monitoring tidak hanya berisi persentase progress, tetapi juga mencakup status pekerjaan, hambatan lapangan, validasi laporan, approval dokumen, serta informasi yang dibutuhkan oleh berbagai pihak untuk mengambil keputusan.

Dalam proyek yang melibatkan banyak organisasi, sistem monitoring perlu menyediakan visibilitas lintas aktor. Kontraktor membutuhkan media untuk melaporkan progress dan hambatan, auditor membutuhkan data untuk validasi, executing agency membutuhkan informasi untuk koordinasi, sedangkan pemberi dana dan pengawas membutuhkan ringkasan status proyek. Oleh karena itu, sistem monitoring harus mampu menghubungkan data operasional dengan proses pengambilan keputusan.

Pada penelitian ini, sistem monitoring dipahami sebagai bagian dari workflow governance. Artinya, sistem tidak hanya menampilkan data terakhir, tetapi juga mengatur bagaimana data dibuat, divalidasi, diubah statusnya, dan dipantau oleh aktor yang berwenang. Pendekatan ini penting karena masalah pada proyek multi-stakeholder sering muncul bukan hanya karena data tidak tersedia, tetapi karena alur proses tidak jelas, status tidak konsisten, atau tanggung jawab antar pihak tidak mudah dilacak.
