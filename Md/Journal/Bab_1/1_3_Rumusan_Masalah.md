# 1.3 Rumusan Masalah

Berdasarkan identifikasi masalah, rumusan masalah dalam penelitian ini adalah sebagai berikut.

1. Bagaimana memodelkan workflow monitoring proyek lintas lembaga menggunakan Finite State Machine?

2. Bagaimana menerapkan access control berbasis organisasi agar setiap aktor hanya dapat menjalankan aksi sesuai kewenangannya?

3. Bagaimana SLA tracking dan audit trail dapat meningkatkan traceability serta accountability proses?

4. Bagaimana outbox pattern dan WebSocket dapat mendukung realtime event delivery tanpa menggantikan REST API sebagai source of truth?

5. Bagaimana pengujian backend dapat membuktikan correctness dari workflow, authorization, SLA tracking, auditability, dan realtime delivery?

Rumusan masalah tersebut membatasi fokus penelitian pada empat pilar utama, yaitu FSM workflow governance, organization-centric access control, SLA tracking dan auditability, serta realtime event delivery.
